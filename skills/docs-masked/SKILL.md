# docs-masked — обезличивание документов до отправки в модель

## Зачем

Когда в модель уходит договор или выгрузка клиентов, туда уходят и чужие
персональные данные. Скилл превращает это в контролируемую операцию: данные
заменяются тегами на локальной машине, наружу уходит текст без людей, а ответ
модели восстанавливается обратно по сейфу, который тоже никуда не уезжает.

```
документ ──▶ маска ──▶ контроль утечки ──▶ модель ──▶ обратная подстановка
           локально      локально          сеть           локально
```

## Порядок работы

Он всегда один и тот же — не пропускай шаги, даже если документ выглядит
безобидно. Пропуск второго шага и есть та ситуация, ради которой скилл нужен.

**1. Посмотреть, что внутри.** Локально, без сети:

```bash
python3 -m pii_shield.cli scan договор.docx
```

Вывод показывает типы и количество находок. Если ожидал персональные данные,
а находок нет — это повод разобраться, а не идти дальше.

**2. Обезличить и убедиться, что чисто.**

```bash
python3 -m pii_shield.cli mask договор.docx
```

Рядом появятся `договор.masked.docx` и `договор.docx.vault.json` (права 0600).
Команда сама прогоняет контроль утечки и завершается с ненулевым кодом, если
что-то осталось.

**3. Отправить в модель только замаскированный текст.** Либо полным кругом:

```bash
python3 -m pii_shield.cli ask договор.docx -p "Найди риски по срокам оплаты"
```

Эта команда сама маскирует, проверяет, отправляет и восстанавливает ответ.
Провайдер задаётся флагом `--provider anthropic|openai|deepseek|ollama`.

**4. Восстановить.** Для ответа модели подстановка уже сделана. Замаскированный
файл возвращается к исходному виду так:

```bash
python3 -m pii_shield.cli unmask договор.masked.docx --vault договор.docx.vault.json
```

## Если работаешь из кода, а не из терминала

Когда нужно вплести обезличивание в свой пайплайн, важно одно: между текстом и
сетью обязан стоять `assert_clean`.

```python
from pii_shield import mask_text, assert_clean, unmask_text

r = mask_text(raw_text)          # r.text — с тегами, r.vault — сейф
assert_clean(r.text)             # LeakGuardError, если что-то осталось
answer = call_model(r.text)      # наружу уходит только маска
final, unknown = unmask_text(answer, r.vault, mode="canonical")
```

Полный круг одной функцией:

```python
from pii_shield import ask_document

res = ask_document("договор.docx", "Составь резюме и найди риски",
                   provider="anthropic")
print(res.answer)                # имена уже восстановлены
```

## Что показать пользователю перед отправкой

Если документ важный или пользователь просит убедиться, собери страницу ревью —
там видно каждую замену в контексте, а значения закрашены и открываются по
наведению:

```bash
python3 -m pii_shield.cli report договор.docx --open
```

Эта страница содержит оригиналы. Она для локального просмотра, её нельзя
пересылать и нельзя коммитить.

## Когда контроль утечки не пропускает

`LeakGuardError` означает, что после маскирования в тексте остались похожие на
персональные данные фрагменты. Правильная реакция — разобраться, а не обходить:

- посмотреть, что именно осталось: `python3 -m pii_shield.cli verify файл`;
- если это внутренний код, название проекта или редкий идентификатор — добавить
  его в файл со списком и передать `--terms термины.txt`;
- если это ложное срабатывание вроде номера версии — `--allow исключения.txt`.

Флаг `--force` существует, но он отправляет данные, не прошедшие проверку, и
пишет это в журнал. Не используй его по своей инициативе — только если
пользователь явно этого попросил, понимая, что именно уходит.

## Границы, о которых стоит сказать вслух

Скилл ошибается в безопасную сторону: лучше скрыть лишнее, чем пропустить.
Но у него есть честные пределы, и о них лучше предупредить сразу:

- **Скан-PDF без текстового слоя** не обрабатывается — нужен OCR.
- **Однофамильцы без инициалов** получают отдельные теги, а не сливаются в
  одного человека.
- **Голые числа без подсказок** (ИНН в свободном тексте без слова «ИНН» и с
  неверной контрольной суммой) могут быть не распознаны как таковые — но
  параноидальный проход всё равно не выпустит такой текст наружу.
- **Произвольные латинские имена** без славянских окончаний и без обращения
  (`Mr.`, `Dr.`) не распознаются: ловить любую пару заглавных слов дало бы
  больше вреда, чем пользы.

Если документ критичный, скажи пользователю посмотреть `report` глазами.

## Установка, если инструмента ещё нет

```bash
git clone https://github.com/kpshinnik/docs_masked.git ~/.docs_masked/src
cd ~/.docs_masked/src && ./install.sh
```

Проверка, что всё на месте: `python3 -m pii_shield.cli selftest`.
