# Командный интерфейс

Вызов: `docs-masked <команда>` после установки или `python3 -m pii_shield.cli <команда>`
из каталога проекта. Псевдоним `pii-shield` работает так же.

## Команды

| Команда | Что делает | Код возврата |
|---|---|---|
| `scan FILE` | Показывает, что будет замаскировано. Файл не меняется, сеть не трогается. | 0 |
| `mask FILE` | Обезличенная копия в том же формате + файл сейфа. | 0, либо 2 если проверка не пройдена |
| `unmask FILE --vault V` | Возвращает оригиналы. | 0 |
| `verify FILE` | Проверяет, что персональных данных не осталось. | 0 чисто, 1 найдено |
| `ask FILE -p "..."` | Полный круг: маска → проверка → модель → восстановленный ответ. | 0, 3 блокировка утечки, 4 ошибка провайдера |
| `report FILE` | HTML-страница ревью: каждая замена в контексте. | 0 |
| `formats` | Поддерживаемые расширения, метки, провайдеры. | 0 |
| `selftest` | Самопроверка круговорота на встроенном примере. | 0 / 1 |

## Общие флаги маскирования

| Флаг | Значение |
|---|---|
| `--style hash\|bracket\|angle` | Формат тега: `#PERSON_1#`, `[[PERSON_1]]`, `<PERSON_1>`. По умолчанию `hash`. |
| `--terms FILE` | Файл со строками, которые нужно скрыть дополнительно: внутренние коды, названия проектов. Одна строка на запись, `#` — комментарий. |
| `--allow FILE` | Файл со строками, которые скрывать не нужно: своя компания, публичные контакты. |
| `--aggressive` | Скрывать одиночные слова, похожие на фамилии, даже без подтверждающего контекста. Повышает полноту и число ложных срабатываний. |
| `--dates` | Скрывать все даты, а не только даты рождения и выдачи документов. |
| `--urls` | Скрывать ссылки. |
| `--off ORG,IP` | Отключить отдельные метки. |
| `--show` | Показывать сами значения в отчёте (по умолчанию только количество). |

## Флаги отдельных команд

**`mask`**

| Флаг | Значение |
|---|---|
| `-o, --out PATH` | Куда положить обезличенную копию. |
| `--vault PATH` | Куда положить сейф. По умолчанию `<файл>.vault.json` рядом. |
| `--pass-env VAR` | Зашифровать сейф парольной фразой из переменной окружения (scrypt + Fernet). |
| `--pdf-redact` | Для PDF: физически вымарать текст и пересобрать файл. Без флага результат сохраняется как `.txt`. |

**`unmask`**

| Флаг | Значение |
|---|---|
| `--vault PATH` | Обязательный. Файл сейфа. |
| `--mode sequential` | По умолчанию. Точное посимвольное восстановление нашего же файла: возвращается исходная словоформа. |
| `--mode canonical` | Для произвольного текста, например ответа модели: подставляется каноничная форма, для ФИО — именительный падеж. |

**`ask`**

| Флаг | Значение |
|---|---|
| `-p, --prompt` | Обязательный. Что сделать с документом. |
| `--provider` | `anthropic` (по умолчанию), `openai`, `deepseek`, `ollama`. |
| `--model` | Переопределить модель провайдера. |
| `--effort low\|medium\|high\|xhigh\|max` | Для Anthropic. По умолчанию `high`. |
| `--max-tokens N` | По умолчанию 16000. |
| `--dry-run` | Показать текст, который ушёл бы в модель, и остановиться. |
| `--keep` | Сохранить и обезличенную копию документа. |
| `--html --open` | Свёрстанный ответ в HTML. |
| `--force` | Отправить, несмотря на непройденную проверку. Пишется в журнал как принудительная отправка. |

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `ANTHROPIC_API_KEY` | Ключ Anthropic. Работает и вход через `ant auth login`. |
| `OPENAI_API_KEY` | Ключ OpenAI. |
| `DEEPSEEK_API_KEY`, `DEEPSEEK_BASE_URL` | DeepSeek, по умолчанию `https://api.deepseek.com`. |
| `OLLAMA_BASE_URL` | По умолчанию `http://localhost:11434/v1`. |
| `PII_SHIELD_ANTHROPIC_MODEL` и аналоги | Модель по умолчанию для провайдера. |
| `PII_SHIELD_LOG` | Путь к журналу отправок. По умолчанию `~/.pii_shield/egress.jsonl`. |
| `DOCS_MASKED_HOME` | Каталог сейфов MCP-сервера. По умолчанию `~/.docs_masked`. |

## Журнал отправок

Каждый вызов модели пишет строку JSON: время, провайдер, модель, размер
запроса, sha256 первых символов, результат проверки утечки, статус и время
ответа. Содержимое запроса не пишется — журнал нужен, чтобы можно было
доказать, что и когда уходило, не храня при этом сами данные.
