# Что распознаётся и в каких форматах

## Типы данных

| Метка | Что это | На чём держится распознавание |
|---|---|---|
| `PERSON` | ФИО в любом падеже, с инициалами, латиницей и транслитом | морфология, словарь имён, суффиксы отчеств и фамилий |
| `ORG` | ООО «…», АО «…», ИП, LLC, GmbH, развёрнутые формы вида «федеральное государственное … «Политехнический институт»» | организационно-правовая форма плюс кавычки |
| `EMAIL` | адреса почты | формат |
| `PHONE` | российские и международные номера | 10–15 цифр плюс префикс, форматирование или контекст |
| `ADDRESS` | индекс, город, улица, дом, корпус, строение, квартира, офис, литера | составной шаблон, маркер улицы до и после названия |
| `BIRTHDATE` | даты рождения | дата плюс «г.р.», «дата рождения», «родился» |
| `DOCDATE` | дата выдачи документа, срок действия | дата плюс «выдан», «дата выдачи» |
| `PASSPORT` | паспорт РФ, загранпаспорт, код подразделения | формат `12 34 567890` или ключевое слово |
| `SNILS` | СНИЛС | контрольная сумма, при ключевом слове — и без неё |
| `INN` | ИНН 10 и 12 знаков | контрольные разряды, при ключевом слове — и без них |
| `OGRN` | ОГРН, ОГРНИП | контрольный разряд или ключевое слово |
| `KPP`, `BIK` | КПП, БИК | ключевое слово, для БИК также префикс `04` |
| `ACCOUNT` | расчётный и корреспондентский счёт | 20 знаков |
| `CARD` | банковские карты | алгоритм Луна |
| `IBAN` | международные счета | mod-97 |
| `POLICY` | полис ОМС и ДМС | ключевое слово |
| `LICENSE` | водительское удостоверение | ключевое слово |
| `PLATE` | автомобильные госномера | шаблон ГОСТ |
| `IP` | IPv4 | формат |
| `HANDLE` | `@никнеймы` | формат |
| `DOCNUM` | ОКТМО, ОКПО, ОКАТО, КБК, ОКВЭД, лицевой счёт | ключевое слово реквизита |
| `CUSTOM` | ваши строки из `--terms` | точное совпадение |

Включаются флагом: `DATE` (все даты), `URL` (ссылки).

## Форматы документов

| Формат | Чтение | Запись на место | Особенности |
|---|---|---|---|
| `.txt` `.md` `.rst` `.log` `.tex` `.yaml` `.ini` `.srt` | да | да | автоопределение кодировки, включая cp1251 |
| `.docx` | да | да | обход по XML: видит абзацы внутри полей контента и надписей, которые `document.paragraphs` пропускает. Правка по `run`, форматирование сохраняется. Таблицы и колонтитулы включены |
| `.xlsx` `.xlsm` | да | да | по ячейкам, заголовок колонки используется как контекст |
| `.csv` `.tsv` | да | да | определение разделителя, заголовок колонки как контекст |
| `.json` | да | да | обход всех строковых значений |
| `.html` `.htm` `.xhtml` | да | да | только текстовые узлы, `script` и `style` не трогаются |
| `.pdf` | да | по флагу `--pdf-redact` | без флага результат сохраняется как текст |
| `.rtf` `.doc` `.odt` | да | нет | через системный `textutil` (macOS) |

## Как контекст помогает

Ячейка `500100732259` сама по себе неотличима от случайного числа. Если она
стоит в колонке «ИНН» или сразу после подписи «ИНН/КПП:», распознавание
срабатывает уверенно. Поэтому таблицы передают заголовок колонки, а короткие
фрагменты — предыдущий фрагмент как подсказку.

## Контроль утечки

После маскирования текст прогоняется повторно всеми детекторами плюс
параноидальный проход: любой `@`, любая цепочка из семи и более цифр, любой
телефоноподобный набор. Ошибка детекции превращается в отказ отправить, а не
в тихую утечку.

Отдельно работает второй проход по остаткам: спан, проигравший более
приоритетному соседу при разрешении перекрытий, ищется заново на очищенном
тексте. Без этого код ОКТМО, перетекающий на следующую строку, скрывал бы
начало соседнего адреса и адрес терялся бы целиком.

## Честные пределы

- **Скан-PDF без текстового слоя** не обрабатывается: нужен предварительный OCR.
- **Однофамильцы без инициалов** получают отдельные теги. Слияние двух людей в
  один тег считается допустимой ошибкой, пропуск данных — нет.
- **Произвольные латинские имена** без славянских окончаний и без обращения
  (`Mr.`, `Dr.`) не распознаются: любая пара заглавных слов давала бы слишком
  много ложных срабатываний.
- **Именительный падеж** восстанавливается по правилам, а не по полному
  словарю: редкие и несклоняемые фамилии остаются как есть.
